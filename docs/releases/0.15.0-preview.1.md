# CBM Sec 0.15.0 Preview 1

程序版本 `0.15.0-preview.1`；发布标签 `cbm-sec-v0.15.0-preview.1`。这是 CBM Sec 的独立预览发布，不是原版 CBM 发行，也不意味着完整静态分析或生产稳定性认证。是否完成发布，以对应 GitHub Release 的公开状态和产物为准。

## 本版内容

在原主线基础上，整合普通资源操作清单、单条完整操作结果缓存和离线证据导出；新增普通 Java 调用实参的来源查询。共十二个只读 MCP 工具。

`trace_argument_origins` 从选定调用的一个实参回溯当前范围内的形参、复制、覆盖和未知来源，不需要 MyBatis 映射或漏洞规则。形参边界不是攻击者可控性分类。原 MyBatis 专用源到点接口继续保留。

`query_resource_operations` 包含普通参数化查询、常量查询、写操作与未连接声明。结构清单不运行局部数据流；选择操作后再显式深入。相同操作的概览和完整展开可复用同一进程最后一条完整结果。

`security/export_evidence.py` 只核对已经保存结果中的源码引用并导出材料，不重新执行分析，不认证结果生产者，也不裁决漏洞。

新发布必须对精确提交重新执行文档检查、GCC 严格构建、Clang 地址/未定义行为/泄漏检查及全部专项回归，并记录构建环境、源码树、程序哈希和实际测试日志。此前候选的测试记录不能代替发布提交的检查。

提供完整源码归档、Linux x86_64 程序与示例、校验清单、构建信息和测试结果。其他平台没有本次二进制兼容性验证。未运行真实 Codex/pi、业务漏洞基准或模型成本评测；不宣称召回率或费用改善。

## 已知边界

普通参数回溯限制为16个明确Java文件、每文件256 KiB、总计2 MiB，最多四层调用者。对象字段和数组内容、通用跨文件返回、复杂重载、继承与运行分派、完整CFG/DFG、循环及异常语义、净化效果均不在本次新增支持范围。

未并入历史CFG/finally、范围扫描、检查点实验；没有修改Sulliu、用户客户端或Hooks设置。许可证、第三方来源、旧标签和旧Release保持不变。

未找到路径、不支持或预算停止不等于没有风险。声明控制和参数传播关系不能直接证明安全控制生效或漏洞成立。
