# CBM Sec 0.15.0 Preview 1 发布说明草稿

**尚未发布，完整候选尚未整合完成。** 当前分支程序版本为 `0.15.0-preview.1`；拟用新标签为 `cbm-sec-v0.15.0-preview.1`。这里只是说明草稿，不是实际 Release 或可下载产物。最新交付与缺失文件见[交付状态](../development/status.md)。

## 拟交付内容

普通 Java 调用实参来源、普通 MyBatis 资源操作清单和单条完整操作结果缓存的核心已进入整合分支，注册十二个只读 MCP 工具。旧 MyBatis 专用源到点接口继续保留。

`trace_argument_origins` 不要求 MyBatis 映射、请求注解或漏洞规则；形参边界不是攻击者可控性分类。`query_resource_operations` 包含参数化、常量、写操作与未连接声明，不默认执行局部值流。同一固定源码进程内的相同操作可复用最后一条完整结果，输出视图不等于分析深度。

原候选中的 `security/export_evidence.py`、新增专项、示例和 Java 参考仍待恢复及整合。导出器的计划职责仅是核对保存结果的源码引用，不重新求解程序关系、不认证结果生产者、不裁决漏洞。
