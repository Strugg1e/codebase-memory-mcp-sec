# 字符串返回模型

对 String.trim/strip/substring/concat/replace 等受支持签名，使用已有参数查询和自动回溯。
新证据会带 jdk_string_return_model、model_id 和修订号，源码位置仍属于固定快照。

先检查类型依据和 unknown_reasons。隐式 String 导入保留外部同名类型未排除的前提；
没有模型的同名方法不能被视为已经追踪。库模型只提供正常返回时的可能依赖，不证明
调用成功、具体字符串值、路径可行或攻击输入满足类型约束。

去空白、替换或转大小写都不自动净化。已知来源、字面量可能性和未知来源可以同时存在。
模型不会修改源到点规则分类，未找到路径不表示安全。
升级分析器后重新创建检查点，不能复用旧构建的结果来假装完成新能力检查。
